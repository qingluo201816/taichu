前端设计章节模板
用途：当规格涉及前端页面/交互变更时，本模板描述前端资产的设计方案，确保前后端对接一致。 触发条件：规格需求中包含新增页面、新增弹窗、修改表格列/操作按钮等 UI 变更。 无 UI 变更时可省略本章节。 技术栈：Vue 3 (Composition API + TSX) + Ant Design Vue + Vuex + Vue Router 4

页面结构（新增页面时必填）
Pattern A（Route-based CRUD） - 适用于复杂表单：

{业务页面目录}/
├── Index.tsx          ← 页面入口（主表格 + 操作栏 + 弹窗触发逻辑）
├── config.tsx         ← 表格列定义、搜索表单配置、操作按钮配置
├── Add.tsx            ← 新增路由页面（委托给 EditForm）
├── Edit.tsx           ← 编辑路由页面（委托给 EditForm）
├── View.tsx           ← 查看路由页面（委托给 EditForm）
└── components/        ← 页面级私有组件
    ├── EditForm.tsx   ← 表单主组件（mode: add/edit/view）
    └── ...
Pattern B（Modal-based CRUD） - 适用于简单表单：

{业务页面目录}/
├── Index.tsx          ← 页面入口（主表格 + 操作栏 + 弹窗触发逻辑）
├── config.tsx         ← 表格列定义、搜索表单配置
└── modals/
    └── DetailModal.tsx ← 新增/编辑/查看弹窗

// src/api/modules/{业务域}/xxxApi.ts
import { Http } from '@/utils/http/axios';
import type { SingleResponse, PageResponse } from '@/types/common';
import type { XxxQuery, XxxDTO, XxxCreateRequest } from './types';

export const API = {
  API_GET_LIST: `${BASE}/xxx/list`,
  API_POST_SAVE: `${BASE}/xxx/save`,
  // ...
};

/**
 * 查询 Xxx 列表
 * @param params 查询参数
 * @returns 分页 Xxx 列表
 */
export function fetchXxxList(params: XxxQuery): Promise<PageResponse<XxxDTO>> {
  return Http.post(API.API_GET_LIST, params);
}

弹窗组件结构（新增时必填）
// src/views/pages/{业务域}/{子模块}/Add.tsx
import { defineComponent, ref } from 'vue';
import { createXxx } from '@/api/modules/{业务域}/xxxApi';
import type { XxxCreateRequest } from '@/api/modules/{业务域}/types';
import { useMessage } from '@/hooks/web/useMessage';

export default defineComponent({
  name: 'AddModal',
  props: {
    visible: { type: Boolean, default: false },
  },
  emits: ['update:visible', 'success'],
  setup(props, { emit }) {
    const { createMessage } = useMessage();
    const formRef = ref();
    const formData = ref<XxxCreateRequest>({ /* 初始值 */ });
    
    const handleSubmit = async () => {
      await formRef.value.validate();
      const { success, msg } = await createXxx(formData.value);
      if (success) {
        createMessage.success('操作成功');
        emit('success');
      } else {
        createMessage.error(msg);
      }
    };
    
    return { formRef, formData, handleSubmit };
  },
});

事件处理流程
核心事件
事件	触发条件	处理方法	执行内容	所在文件

表单提交	点击提交	handleSubmit()	验证表单，调用 API，关闭弹窗	Add.tsx/Edit.tsx
前后端交互流程
用户操作（搜索/新增/编辑/删除）
    │
    ├── 1. 组件 Handler（Index.tsx handleXxx()）
    │     │
    │     ├── 2a. useTable.reload() → 触发 API
    │     │     │
    │     │     ├── 3. Http.post(url, params)（xxxApi.ts）
    │     │     │     │
    │     │     │     ├── 4. Axios 拦截器（添加 token、lang 等）（src/utils/http/axios/index.ts）
    │     │     │     │
    │     │     │     ├── 5. 后端 Controller → Service → DB
    │     │     │     │
    │     │     │     └── 6. 响应 { code: '0', result, msg }
    │     │     │
    │     │     └── 7. BasicTable 更新数据、分页（src/components/Table/）
    │     │
    │     └── 2b. 直接 API 调用（save/edit/delete）
    │           │
    │           ├── 3. const { success, msg } = await apiCall()（xxxApi.ts）
    │           │
    │           ├── 4. createMessage.success/error（src/hooks/web/useMessage.tsx）
    │           │
    │           └── 5. reload() 或 router.push()
    │
    └── 8. 用户界面更新（Vue 响应式更新）
