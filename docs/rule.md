# 项目规则

> 更新日期：2026-07-10

## 文件命名

- docs目录下的文件名必须使用**中文**命名,除了rule.md本身
- 文件名应清晰表达文件内容

## 文档规范

- 每个文档必须包含**更新日期**
- 根目录 `README.md` 是唯一仓库地图；新增、移动或删除资料入口时必须同步更新。
- 同一主题只能有一个当前规则源；临时方案、任务记录和历史快照不得自称当前强制规则。
- `docs/临时架构/` 保存未完全落地、仍需核对代码或包含未来规划的架构资料。
- `docs/临时产品文档/` 保存尚未确认为当前产品契约的需求与规划。
- `docs/历史/` 保存有追溯价值但不再指导当前实现的快照。
- 临时目录和历史目录中的文件以目录级说明为状态标记，不要求逐份重复声明。
- 代码枚举、Schema、主题 token 和接口字段以代码为准；文档说明职责和入口，不复制维护第二份完整定义。
- 不在持久文档中混入 `//` 形式的临时 AI 指令。
- 不创建或保留 `.gitkeep`；需要的目录由代码或工具按需创建。
