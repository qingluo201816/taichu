# 石墨粉笔瑞士网格风格

> 更新日期：2026-07-01

> 状态：已登记主题的参考说明。强制边界以根目录 `DESIGN.md` 为准，精确 token 以 `web/src/app/globals.css` 为准。

## 风格定位

风格 ID：`graphite-chalk-swiss`

本风格参考“brutalist Swiss grid in graphite and chalk”的设计语言：纯白画布、石墨文字、1px 发丝线边框、紧凑网格、低装饰、高结构感。它适合把太初界面转译为一种近似设计系统文档站的写作工具：每个模块都像排在绘图桌上的组件样张，所有层级由边框、网格、字号和间距建立。

该风格不是普通后台，也不是营销页。它应保持太初的写作助手身份，只把视觉表达改成严格黑白灰、结构优先、组件预览感更强的界面。

## 视觉原则

- 页面主画布使用纯白或近白，所有卡片也保持白色，通过 1px 边框分隔。
- 结构色只使用黑、白、灰，不引入彩色品牌色。
- 主要操作使用唯一的黑色填充按钮，其他操作使用文字按钮、描边按钮或浅灰 hover。
- 卡片、输入框、导航和列表都依赖发丝线边框，不依赖阴影。
- 字体使用 Geist 或 Inter 一类几何无衬线字体，整体紧凑、清晰、工具化。
- 页面布局保留太初原有信息结构，但视觉密度更高，区块间距更克制。
- 图像和插画不是主视觉，组件自身、表单、列表、资料卡和编辑器片段就是视觉内容。

```css

  --style-graphite: #0a0a0a;

  --style-carbon: #171717;
  --style-concrete: #737373;
```

## 字体与排版

推荐字体：

```css
:root[data-theme-style="graphite-chalk-swiss"] {
  --tc-font-display: "Geist", "Inter", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
  --tc-font-ui: "Geist", "Inter", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
  --tc-font-mono: "Geist Mono", "JetBrains Mono", "SFMono-Regular", Consolas, monospace;
}
```

排版规则：

- 所有 UI、标题、正文、按钮、标签和导航优先使用 Geist 或 Inter。
- 展示标题建议 40px 到 48px，字重 600。
- 正文建议 14px 到 16px，行高 1.43 到 1.6。
- 标签、徽标和元信息建议 12px 到 13px。
- 全局 `letter-spacing` 保持 `0`。参考风格里的紧字距效果不直接照搬，通过字重、网格和紧凑间距实现。
- 中文长文阅读场景可适当放宽行高，不能为了紧凑牺牲编辑器可读性。

## 间距、圆角与边框

```css
:root[data-theme-style="graphite-chalk-swiss"] {
  --tc-space-section: 48px;
  --tc-space-card: 16px;
  --tc-space-element: 8px;

  --tc-radius-control: 10px;
  --tc-radius-card: 14px;
  --tc-radius-badge: 26px;
  --tc-radius-pill: 9999px;

  --tc-shadow-card: none;
  --tc-shadow-panel: none;
  --tc-motion-fast: 120ms;
  --tc-motion-normal: 180ms;
}
```

规则：

- 按钮、输入框、导航项使用 10px 圆角。
- 卡片使用 14px 圆角。
- 标签使用 26px 或全圆角。
- 所有主要结构边框使用 1px `--style-hairline`。
- 不使用真实投影；最多允许 1px 外描边式 ring。
- 区块间距紧凑，页面不追求大幅留白。

## 组件规则

### 导航

- 白底，无大面积填充。
- 高度建议 56px 到 64px。
- 底部使用 1px 发丝线分隔。
- 当前模块可使用浅灰底或黑色文字加粗，不使用彩色激活态。

### 主按钮

- 每个视觉区域只保留一个黑色填充按钮。
- 背景 `--style-graphite`。
- 文字 `--style-chalk`。
- 圆角 10px。
- 无阴影。
- hover 可轻微提亮到 `--style-carbon`。

### 次级按钮

- 使用文字按钮、ghost 按钮或 1px 边框按钮。
- hover 使用 `--style-mist` 背景。
- 不出现第二个填充黑按钮。

### 卡片

- 白底。
- 1px `--style-hairline` 边框。
- 14px 圆角。
- 16px 到 20px 内边距。
- 标题 16px 到 18px，字重 600。
- 说明文字使用 `--style-concrete`。
- 不使用插画作为卡片主视觉，内容结构本身就是视觉。

### 表单与输入

- 白底。
- 1px `--style-hairline` 边框。
- 10px 圆角。
- placeholder 使用 `--style-concrete`。
- focus 时边框变为 `--style-graphite`，或出现极细外描边。

### 标签与状态

- 标签使用 `--style-mist` 背景或白底描边。
- 状态差异优先通过文字、图标、边框和位置表达。
- 不用彩色表达成功、警告、错误。必要时使用中文说明和图标。

### AI 结果与来源

- AI 结果卡保持白底发丝线。
- “AI 生成”“来源”“待确认”等标识使用浅灰标签。
- 主要操作仍遵守单一黑色主按钮规则。
- 来源编号可以使用等宽字体，但必须配中文说明。

## 禁止项

- 禁止任何彩色按钮、彩色链接、彩色状态点或彩色渐变。
- 禁止大面积阴影和浮夸悬浮卡片。
- 禁止使用衬线展示字体、手写字体或装饰字体。
- 禁止使用纯营销式 hero、插画主视觉或生活方式图片。
- 禁止同一区域出现多个黑色填充按钮。
- 禁止新增页面结构或改变组件功能来适配风格。
- 禁止直接复制参考站点的英文导航、示例数据或业务语义。

## 太初适配说明

该风格用于太初时，应把写作场景表达为“结构化写作工作台”：

- 首页像一组清晰的功能样张，而不是情绪化品牌页。
- 编辑器像白色稿纸嵌入组件网格，但正文可读性必须优先。
- 知识库像可筛选、可归档的资料组件网格。
- 收件箱像待处理组件队列。
- 对话与来源证据像文档站中的可追溯示例块。

## 验收重点

- 全站没有彩色视觉残留。
- 所有主要卡片、输入、导航、列表都使用 1px 发丝线分隔。
- 每个视觉区域最多一个黑色填充主按钮。
- 编辑器正文、资料卡和来源证据在 14px 到 16px 下仍然可读。
- 页面结构和功能与其他风格保持一致。
