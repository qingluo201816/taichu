# 午夜极光控制台风格

> 更新日期：2026-07-01

## 参考来源

本风格参考 Langbase Midnight aurora console：炭灰控制台画布、深色导航条、灰色线框、白色胶囊按钮，以及只作为装饰出现的多色极光横条。

## 风格定位

该风格是太初当前默认主风格，对应主题 ID：

```text
langbase-midnight-console
```

它把太初塑造成一个中文玄幻写作控制台。视觉重点是长期写作、资料检索、章节编辑和 AI 协作时的清晰结构，而不是营销页或游戏化界面。

## 核心视觉规则

- 页面背景使用 `#232324` 炭灰控制台画布。
- 顶部导航使用 `#0e0e10` 深色横条。
- 卡片和面板以同色或内凹深色表面承载内容。
- 边框和分割线使用 `#5c5c61` 灰色线框。
- 主文字使用 `#fafafa`，次级文字使用 `#a1a1aa`。
- 主按钮使用白底黑字胶囊形。
- 卡片使用 12px 圆角，输入框和小标签使用 4px 圆角，按钮使用全圆角。
- 极光渐变只作为装饰，不作为按钮、文字、边框、图标或功能状态颜色。
- 项目全局不允许负字距，因此外部参考中的负 tracking 在太初实现中统一适配为 `letter-spacing: 0`。

## 组件规则

- 主按钮使用白色胶囊按钮，不使用彩色按钮。
- 次级按钮使用透明或深色背景、1px 灰色边框和浅色文字。
- 卡片使用炭灰背景、12px 圆角、1px 灰色边框。
- 输入框使用 `#181818` 内凹背景、4px 圆角和灰色边框。
- 图标使用单色线性图标。
- 标签必须有中文文字，不得只靠颜色表达状态。

## 禁止项

- 禁止把极光渐变作为功能色。
- 禁止彩色按钮体系。
- 禁止纯黑作为页面背景。
- 禁止厚重投影。
- 禁止玻璃拟态。
- 禁止大面积渐变背景。
- 禁止恢复 Axiom 纯黑橙色终端风格作为默认主风格。
- 禁止使用英文内部字段名作为用户可见文案。
