# 入口页状态说明

> 更新日期：2026-07-11

## 当前状态

太初暂不启用独立点云入口。访问前端根路径 `http://localhost:3000/` 时，由 Next.js 服务端直接跳转到 `http://localhost:3000/home`。

`/home` 是当前正式主入口，继续使用根目录 `DESIGN.md` 定义的午夜极光控制台风格。首页当前使用本地静态图片作为全屏内容背景，按 `cover` 方式适配视口；纯色页面背景作为加载和兼容性降级。

首页导航和入口表面使用无模糊的低透明深色覆盖层、白色细边和白灰文字，让背景图片保持可见。该透明样式只用于首页背景之上的操作层，不扩散到其他功能页面，也不使用玻璃模糊、厚阴影或发光边框。

首页正文区域只保留四个主要入口：写作、智能体工作台、任务监控、知识库。桌面端入口组放置在页面左侧区域，从页面宽度约 8% 处开始，占据约 28% 页面宽度，按单列纵向排列；窄屏回落为居中的紧凑单列。不放置额外标题或说明。

收件箱、AI 历史、模型监控和设置不再在首页正文区域重复展示，仍可通过顶部全局导航进入。该调整不改变各功能页面的路由与工作流。

## 隔离方式

- 根路由只保留 `/home` 重定向，不再导入点云入口组件。
- 点云入口源码、点云模型和星球贴图已从 `web/` 活动目录移出。
- 仅供点云入口使用的 `three`、`gsap` 和 `@types/three` 已从活动前端依赖中移除。
- 历史实现不参与 TypeScript 检查、ESLint、Next.js 构建和静态资源发布。

## 当前首页背景素材

首页背景图片位于：

`web/public/home/tree-background-static.png`

该素材只服务 `/home`，不得扩散为编辑器、知识库、智能体工作台或任务监控等功能页面的背景。替换背景时应保持文件路径稳定，避免把素材选择耦合进页面组件逻辑。
