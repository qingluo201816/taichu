# 前端风格索引

> 更新日期：2026-07-12

## 目录用途

本目录保存前端主题参考资料和入口状态说明，不是前端强制规则源。

根目录 `DESIGN.md` 是当前前端设计唯一强制规则源。主题清单与默认值以 `web/src/components/theme/theme-registry.ts` 为准，精确 token 以 `web/src/app/globals.css` 为准；本目录不复制维护第二份代码事实。

## 资料入口

- `7-1石墨粉笔瑞士网格风格.md`：已登记可切换主题的视觉参考，强制边界与实际实现仍分别以 `DESIGN.md` 和前端代码为准。
- `7-11入口页状态说明.md`：当前根路由、首页视觉隔离方式和历史点云备份位置。

多风格切换的允许项、禁止项和新增边界统一见根目录 `DESIGN.md` 的“多风格切换边界”与“明确禁止项”。
