# 前端风格索引

> 更新日期：2026-07-10

## 目录用途

本目录只保存可切换主题的参考说明，不是前端强制规则源。

根目录 `DESIGN.md` 是当前前端设计唯一强制规则源。主题清单与默认值以 `web/src/components/theme/theme-registry.ts` 为准，精确 token 以 `web/src/app/globals.css` 为准；本目录不复制维护第二份代码事实。

## 风格包边界

每套风格允许改变：

- 颜色。
- 字体。
- 圆角。
- 边框。
- 阴影。
- 局部动效强度。

每套风格不允许改变：

- 页面信息结构。
- 组件功能。
- 路由与工作流。
- 用户可见中文文案规则。
- 单本玄幻小说写作助手的产品边界。

## 后续新增规则

- 新增主题说明使用中文命名 Markdown 文件；若仅修改实现 token，不强制创建说明文档。
- 文件必须包含更新日期。
- 文件必须说明该风格如何映射到统一语义 token。
- 文件必须明确该风格的禁止项。
- 不复制外部参考产品的英文文案、客户 logo、业务语义或示例数据。
