# 前端风格索引

> 更新日期：2026-07-01

## 目录用途

本目录用于沉淀太初未来可一键切换的前端风格包。每一套风格单独成文，记录参考来源、视觉原则、token 映射、组件规则、允许变化范围和验收重点。

根目录 `TAICHU_DESIGN.md` 仍作为当前前端设计强制规则源；本目录用于沉淀可切换风格包。实现风格切换时，应把这里的风格文档转译为 `web` 侧主题包，而不是把所有风格内容追加进 `TAICHU_DESIGN.md`。

## 风格包边界

每套风格允许改变：

- 颜色。
- 字体。
- 圆角。
- 边框。
- 阴影。
- 局部动效强度。

每套风格不允许改变：

- 页面信息结构。
- 组件功能。
- 路由与工作流。
- 用户可见中文文案规则。
- 单本玄幻小说写作助手的产品边界。

## 后续新增规则

- 新增风格必须单独创建一个中文命名 Markdown 文件。
- 文件必须包含更新日期。
- 文件必须说明该风格如何映射到统一语义 token。
- 文件必须明确该风格的禁止项。
- 不复制外部参考产品的英文文案、客户 logo、业务语义或示例数据。
