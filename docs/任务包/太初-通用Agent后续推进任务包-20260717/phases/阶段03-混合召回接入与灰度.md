# 阶段 03：混合召回接入与灰度

> 更新日期：2026-07-18
> 阶段编号：`P03`  
> 依赖：`P02=GO_TO_HYBRID_SHADOW`  
> 若阶段 02 为 `HOLD_HYBRID_*`：本阶段标记 `SKIPPED_BY_GATE`，不得强行融合；阶段 02 的独立向量能力继续保留和优化。

## 一、阶段目标

在统一召回内部组合词法与向量候选，通过影子、灰度、回退和评测证明稳定收益。业务 Tool、Agent 和 Workflow 继续只看到标准 `RetrievalResult`。

## 二、融合方案

第一生产候选采用 Reciprocal Rank Fusion（RRF），原因：

- 词法分数和余弦相似度量纲不同。
- RRF 只依赖排名，稳定、可解释、无需先做复杂分数校准。
- 可以单独配置词法/向量权重。
- 任一分支不可用时可自然回退。

不建议第一步就用 LLM 重新排序。只有 RRF 达标但仍有明确排序瓶颈时，再建立独立 reranker 实验，不能把 Agentic RAG 混入本阶段。

## 三、任务清单

### `HBR-001` 实现混合后端

建议新增：

- `src/taichu/infrastructure/retrieval/hybrid_backend.py`
- `src/taichu/application/retrieval/fusion.py`

输入：

- 同一个 `RetrievalRequest`。
- 词法后端。
- 向量后端。
- 融合策略快照。

输出：

- 标准 `RetrievalBackendResult`。
- 每个候选包含词法排名、向量排名、RRF 贡献和最终排名。
- 确定性 tie-break：最终分、最佳分支排名、更新时间、卡片 ID。

限制：

- 只对 `relevance` 启用。
- `identity`、`catalog` 保持原确定性实现。
- 两个分支并发执行，但受统一超时和取消控制。
- 向量分支失败时返回词法结果并记录回退。
- 词法分支失败时默认整体失败；是否允许仅向量结果必须通过单独安全评测，第一阶段不启用。

### `HBR-002` 扩展策略配置

生产策略至少支持：

- `lexical`
- `vector_experiment`
- `hybrid_shadow`
- `hybrid`

建议配置：

- 默认仍为 `lexical`。
- 可按消费者指定策略。
- 权重、RRF 常数、分支 top-k、超时和回退。
- 配置快照随 trace 和检查点保存。

无效配置在启动时失败。不得在运行中使用全局可变“当前策略”导致并发任务互相覆盖。

### `HBR-003` 影子模式

`hybrid_shadow` 行为：

- 正式返回词法结果。
- 后台并发执行向量和融合。
- 记录两者排名差、预计命中变化、耗时和失败。
- 不把影子结果交给 LLM，不改变用户答案。
- 受独立预算限制；不能拖慢正式返回超过配置阈值。
- 影子任务在请求取消后应取消，不制造无界后台任务。

先只对通用 Agent 的 `retrieve_knowledge` 启用影子，再观察写作区和 Workflow。

### `HBR-004` 差异评测与回放

新增按 `retrieval_id` 对比：

- 词法命中。
- 向量命中。
- 融合命中。
- 参考相关卡。
- 增益/损失原因。
- 分支耗时。
- 索引快照。
- 失败和回退。

支持对历史 trace 的脱敏回放，但回放必须冻结知识快照或明确标记当前快照变化，不能把不同数据版本直接比较。

### `HBR-005` 通用 Agent 小流量灰度

只有影子评测达标后：

1. 对评测运行和显式内部测试使用 `hybrid`。
2. 对通用 Agent 事实问答灰度。
3. 验证 `canon_evidence` 的来源完整性和最终答案质量。
4. 验证成本、延迟和空结果。
5. 发生回归时一键切回 `lexical`，无需迁移数据。

工作台可显示“知识召回策略”和索引状态，但默认保持紧凑，不展示完整分数。

### `HBR-006` 扩大消费者

按顺序：

1. 通用 Agent。
2. 章节摘要。
3. 写作区单步任务。
4. 知识沉淀 Workflow 的相关性读取。

身份匹配和有效目录读取始终不切换向量。每扩大一个消费者都重新跑其业务测试和评测，不能一次性全开。

### `HBR-007` 运维与回滚

提供：

- 当前策略、索引 ID、过期状态。
- 词法/向量/混合命中和 p95。
- 向量失败率、回退率。
- 影子差异。
- 一键禁用向量。
- 索引重建。
- 配置回滚。

不得允许前端直接编辑任意 JSON 策略；策略更改走受校验的设置或环境配置。

## 四、验收门禁

沿用总路线图，并增加：

- 影子运行至少覆盖完整评测集和一批真实只读任务。
- 混合策略在三次重复评测中达到晋级门禁。
- 通用 Agent 核心事实问答没有来源回归。
- 向量不可用、索引过期、索引损坏时均返回词法结果。
- 切换回 `lexical` 不需要重启或数据迁移，若当前架构只能启动时配置，则明确重启回滚步骤。
- 写作区与知识沉淀 Workflow 未在未验证前被切换。
- 全量测试、前端和固定端口验证通过。
