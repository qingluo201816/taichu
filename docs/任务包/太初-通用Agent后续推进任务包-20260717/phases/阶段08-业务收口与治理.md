# 阶段 08：业务收口、灰度与治理

> 更新日期：2026-07-17  
> 阶段编号：`P08`  
> 依赖：前述阶段已完成、PASS_WITH_LIMITS、NO-GO 或 SKIPPED，并有明确记录  
> 默认连续执行：是

## 一、阶段目标

把已通过门禁的能力收口为可长期运行的产品能力，删除实验旁路和失效配置，形成真实支持矩阵、监控告警、数据保留策略和回滚手册。

本阶段不要求向量、自适应路由或语义裁判都必须上线；NO-GO 也是合法输入。收口目标是系统边界清楚、默认安全、可观测、可回退。

## 二、任务清单

### `ROL-001` 汇总阶段结论

建立总表：

- 能力。
- 当前状态：生产/灰度/影子/实验/NO-GO。
- 默认配置。
- 适用消费者。
- 评测集校验和。
- 质量指标。
- 延迟/费用。
- 回退路径。
- 已知边界。
- 负责人操作入口。

删除任何“已经完成”但没有代码、测试或评测证据的描述。

### `ROL-002` 确认生产默认值

至少确认：

- 相关性召回默认策略。
- 向量索引过期时行为。
- 记忆默认开关、范围、预算和保留期。
- 会话继续默认行为。
- 模型路由默认策略、硬覆盖和熔断参数。
- Runtime 最大计划节点数、并发、重规划和时限。
- 自动恢复与人工对账边界。
- 语义评测是否只辅助或参与策略晋级。
- 经验提示是否默认关闭、影子或灰度。

所有默认值来自前述评测，不凭感觉设置。

### `ROL-003` 统一特性开关和回滚

特性开关需受校验，至少覆盖：

- `retrieval.strategy`
- `retrieval.vector.enabled`
- `agent_memory.enabled`
- `agent_memory.compaction.enabled`
- `model_routing.mode=static|adaptive`
- `checkpoint.format`
- `semantic_evaluation.enabled`
- `experience_hints.mode=off|shadow|active`

避免散落多个环境变量和前端本地开关形成双重真相。若采用 JSON 配置，启动时做完整 Schema 校验并输出中文错误。

每个开关有：

- 默认值。
- 生效范围。
- 需要重启与否。
- 回滚步骤。
- 数据兼容影响。
- 监控验证。

### `ROL-004` 监控与告警

在已有节点监控、模型监控和评测页面上增加必要聚合：

- 召回命中、空结果、回退、索引过期。
- 记忆命中、压缩、约束丢失保护、上下文预算。
- 模型路由分布、熔断、回退、费用和延迟。
- checkpoint 写入、损坏、恢复、对账和人工介入。
- 语义评测校准状态。
- 经验提示命中和收益。

告警必须有可执行动作，不只展示红色状态。前端保持紧凑，详情按需展开。

### `ROL-005` 数据保留、删除与重建

为以下目录定义：

- `derived/retrieval`
- `derived/embedding_usage`
- `derived/general_agent_memory`
- `derived/model_routing`
- `derived/general_agent_runs`
- `derived/general_agent_experience`
- `generated/vector_indexes`
- `generated/agent_memory_indexes`
- `generated/general_agent_experience_indexes`

每类说明：

- 是否可重建。
- 来源。
- 默认保留期。
- 删除影响。
- 引用依赖。
- 脱敏。
- 备份。
- 清理命令。
- 损坏恢复。

任何目录职责变化同步 `project_assets/readme.md`。

### `ROL-006` 安全与数据审计

自动扫描：

- 密钥、鉴权头。
- 完整 Prompt。
- 完整用户输入。
- 大段正文。
- 外部页面全文。
- Mongo 未确认知识。
- 已拒绝/软删除记忆。
- 已废弃经验。
- `.gitkeep`。
- 旧 JSON 知识路径。
- SQLite/FTS 依赖。
- `project_id` 或多小说入口。

生成审计报告并修复真实问题。

### `ROL-007` 全链路回归

至少覆盖：

1. 写作区单步问答。
2. 章节摘要。
3. 知识沉淀单章和批量。
4. 通用 Agent 直接回答。
5. 通用 Agent 事实问答。
6. 多能力并行。
7. 多轮记忆。
8. 长上下文压缩。
9. 模型故障回退。
10. 写入授权。
11. 进程中断恢复。
12. 召回索引过期回退。
13. 语义评测。
14. 经验提示影子/灰度。
15. 节点监控。
16. 模型监控。
17. 评测历史与删除。

全量命令、固定端口和桌面浏览器均通过。

### `ROL-008` 文档收口

更新：

- `README.md` 仓库地图。
- `AGENTS.md` 仅在不可变决策变化时。
- `project_assets/readme.md`。
- `docs/已讨论功能/通用写作助手智能体架构与能力演进决策.md` 的状态和入口。
- 临时架构文档状态。
- 每阶段历史实现报告。
- 运维和回滚手册。

删除或归档被代码超越的临时说明，不能让“未实现”与“已上线”同时存在于当前说明。

### `ROL-009` 发布真实支持矩阵

至少包含：

- 生产召回策略。
- 向量是否上线及 GO/NO-GO 原因。
- 索引重建命令和故障回退。
- 记忆范围、预算、保留、作者控制。
- 模型角色路由和固定方式。
- 可稳定支持的节点数/并发/任务类型。
- 自动恢复和人工对账边界。
- 语义评测可信范围。
- 经验提示激活范围。
- 已知风险和下一次重评条件。

### `ROL-010` 最终自检与清理

- 删除实验专用旁路、重复服务、失效配置和无引用代码。
- 保留评测夹具和历史报告。
- 不删除用于恢复和对账的证据。
- 不新增品牌化称呼。
- 不提交或推送，除非用户明确授权。
