### `BAS-005` 固化当前能力样例

使用当前生产能力完成一组不修改事实源的基线任务：

1. 直接回答：不应创建 DAG 节点。

3. 单专业 Agent 分析。
4. 两个可并行节点的多能力任务。
5. 需要澄清的任务。
6. 正文写入预览并停在作者授权，禁止真正写入。
7. 一次失败后恢复。
8. 当前 8 个通用 Agent 核心评测样例。

冻结以下信息：

- 最终状态和节点数。
- 能力路径。
- 计划修订次数。
- 来源数。
- 总耗时。
- LLM Token 和费用。
- 召回候选数、命中数和耗时。
- 检查点修订数。
- 当前评测得分。

不得把包含完整正文或 Prompt 的快照提交到仓库；基线夹具只保存必要的结构化、脱敏信息。
