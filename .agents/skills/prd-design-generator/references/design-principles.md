# 设计原则

## 太初架构原则

- 单本玄幻小说上下文，不设计多小说切换、多租户或 `project_id`。
- `domain` 层保持技术无关。
- 应用层负责服务、Agent、Tool 和用例编排。
- 基础设施层实现存储、检索、LLM、MCP 和索引。
- 跨层契约优先使用 `typing.Protocol`。
- 新增 Agent 等同于新增插件目录并实现协议。

## 前端原则

- 前端位于 `web/`。
- 使用 Next.js、shadcn/ui、Tailwind CSS。
- 修改前端页面、组件、样式或文案时必须遵循根目录 `DESIGN.md`。
- 用户可见文本必须是中文。

## 验证原则

- 设计文档必须列出受影响文件和验证命令。
- 修改启动关键文件时必须验证 `start.bat`，或记录无法验证原因。
