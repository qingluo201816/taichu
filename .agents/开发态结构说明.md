# 太初开发态结构说明（.agents）

> 更新日期：2026-07-06

## 定位

`.agents/` 是太初当前有效的 Codex 项目级工作流目录，承载项目级 Skills、任务包和面向 Codex 的开发执行规则。当前有效 Skill 规则源是 `.agents/skills/rule.md`。

如果旧说明提到 `.claude/skills/rule.md` 或 `.Codex/skills/rule.md`，以 `.agents/skills/rule.md` 为准。

## Codex 是否能调用 PRD-to-Plan 流程

可以。

当前 PRD-to-Plan 流程已经作为项目级 Skills 放入 `.agents/skills/`：

- `prd-to-plan`：PRD 到代码实现的总编排入口。
- `prd-plan-analyze`：从 `prd-docs/` 读取 PRD，拆分功能点清单。
- `prd-spec-develop`：从功能点清单推进规格开发全流程。
- `prd-to-ccsdd`：将功能点转成 `.kiro/specs/` 下的 cc-sdd 规格。
- `prd-design-generator`：生成规格技术设计文档。
- `prd-spec-impl`：生成任务清单、执行实现和验证。

在新的 Codex 会话中，用户可以直接说：

```text
使用 prd-to-plan 读取 prd-docs/xxx.md，版本号 V1.0，生成功能点清单。
```

也可以分阶段调用：

```text
使用 prd-plan-analyze 分析 prd-docs/xxx.md，版本号 V1.0。
使用 prd-spec-develop 继续 out/V1.0/功能点清单.md。
```

注意：当前会话的 Skill 列表可能不会自动热更新；如果 Codex 尚未在可用 Skill 列表中看到这些新增 Skill，可以直接按对应 `SKILL.md` 的流程执行，或开启新会话后再调用。

## 当前目录职责

```text
.agents/
├── skills/
│   ├── rule.md                         # 当前有效的项目级 Skill 编写规则
│   ├── prd-to-plan/                    # PRD-to-Plan 总编排
│   ├── prd-plan-analyze/               # PRD 功能点分析
│   ├── prd-spec-develop/               # 规格开发编排
│   ├── prd-to-ccsdd/                   # 功能点转 cc-sdd 规格
│   ├── prd-design-generator/           # 技术设计文档生成
│   ├── prd-spec-impl/                  # 任务与实现
│   └── taichu-*                        # 太初既有执行、发布、验收和 UI 规则 Skill
└── taskpacks/                          # GPT Pro 产出的任务包归档
```

## PRD-to-Plan 调用链

```text
prd-to-plan
├── prd-plan-analyze
│   └── 输出 out/{版本号}/功能点清单.md
└── prd-spec-develop
    ├── prd-to-ccsdd
    │   └── 输出 .kiro/specs/{版本号}/{功能名}/requirements.md
    ├── prd-design-generator
    │   └── 输出 .kiro/specs/{版本号}/{功能名}/design.md
    └── prd-spec-impl
        └── 输出 tasks.md、代码实现、验证结果和实现报告
```

## 使用边界

- 任何代码变更前仍必须先说明方案并获得用户确认。
- 涉及前端时必须遵循 `TAICHU_DESIGN.md` 和 `.agents/skills/taichu-ui-components/SKILL.md`。
- 涉及 Skills 创建、修改或讨论时必须先读取 `.agents/skills/rule.md`。
- Python 命令统一使用 `uv run python`。
- 不设计多小说、多租户、`project_id` 或跨小说切换。
- PRD 默认从 `prd-docs/` 读取，不接入 Confluence、Graphify 或企业认证流程。

## 验证方式

新增或修改 Skill 后，运行：

```powershell
$env:PYTHONUTF8='1'
uv run python C:\Users\wyh\.codex\skills\.system\skill-creator\scripts\quick_validate.py .agents\skills\prd-to-plan
```

对 PRD-to-Plan 全套 Skill，应分别校验 6 个 `prd-*` Skill 目录。
