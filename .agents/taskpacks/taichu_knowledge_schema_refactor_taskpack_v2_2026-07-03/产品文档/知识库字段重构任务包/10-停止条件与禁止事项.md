# 停止条件与禁止事项

## 必须停止并询问用户

出现以下情况时必须停止：

1. 发现用户明确要求保留旧数据的最新文档与本任务包冲突。
2. 无法判断实际 Coding Agent 规则文件位置。
3. 清理旧数据前没有完成 Phase 0 证据返回。
4. 需要修改非知识库核心模块才能继续。
5. 测试失败且无法判断是否由本阶段引入。
6. 发现前端硬编码大量旧字段，改动会扩大到非知识库页面。
7. 发现旧代码强依赖 `source_refs` 且影响 Inbox/AI 历史主流程，需要用户确认重构边界。

## 禁止事项

1. 禁止把 `body` 做成隐藏字段或高级字段。
2. 禁止把 `tags` 做成隐藏字段或高级字段。
3. 禁止保留 `fields` 包裹对象。
4. 禁止保留 `confidence`。
5. 禁止保留知识卡 `source_refs`。
6. 禁止保留 `relations`。
7. 禁止保留 `foreshadow`。
8. 禁止保留 `personality`、`motivation`、`appearance`。
9. 禁止迁移旧卡片。
10. 禁止兼容旧 `confirmed` 状态。
11. 禁止前端展示英文内部枚举。
12. 禁止把章节展示序号当作章节引用保存。
13. 禁止在停机点前自动 commit。
14. 禁止自动进入下一阶段。
