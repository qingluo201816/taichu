# 类型字段契约 v2

## 角色 character

角色卡第一版保留“身份摘要 + 关键状态入口”，不做复杂关系图谱。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `role_type` | enum | 角色定位 | 主角、配角、反派、路人、势力代表 |
| `identity` | short_text | 身份 | 出身、身份、公开身份 |
| `relationship_summary` | long_text | 关系摘要 | 人际关系摘要，只放概述 |
| `death_chapter_id` | chapter_ref/null | 死亡章节 | 若死亡，则记录死亡确认章节 |
| `current_realm_text` | short_text | 当前境界 | 当前境界文本，如“筑基中期”或模糊信息 |
| `first_seen_chapter_id` | chapter_ref/null | 首次登场章节 | 引用稳定 chapter_id |
| `last_seen_chapter_id` | chapter_ref/null | 最近出现章节 | 引用稳定 chapter_id |

`role_type` 选项：

| value | 中文 |
|---|---|
| `protagonist` | 主角 |
| `supporting` | 配角 |
| `antagonist` | 反派 |
| `passerby` | 路人 |
| `faction_representative` | 势力代表 |

第一版明确不要：

```text
personality
motivation
appearance
relations
current_goal
secret
known_secrets
```

人物关系第一版只用 `relationship_summary`，不做关系数组。

## 境界 realm

境界卡记录大小境界，例如练气一层、筑基中期。它为角色状态、战力判断、世界规则提供稳定参照。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `system` | string | 修炼体系 | 所属修炼体系 |
| `level_order` | number | 境界排序值 | 数值越大表示境界越高 |

建议排序区间：

```text
练气一层～九层：11～19
筑基初期/中期/后期：21、25、29 或 21、22、23
金丹：31～
```

第一版明确不要：

```text
parent_realm_id
breakthrough_condition
ability_boundary
cost_or_risk
typical_manifestation
```

有特殊设定写进 `summary`。

## 功法 technique

功法卡区分修炼法门、战斗招式、秘术禁法、辅助技艺。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `technique_type` | enum | 功法类型 | 功法、术法、神通、剑诀、禁术、炼丹、阵法等 |
| `grade` | string | 品阶 | 品阶，第一版不强制枚举 |
| `practice_condition` | long_text | 修炼条件 | 修炼、施展或学习条件 |
| `owner_faction_id` | knowledge_ref/null | 所属势力 | 所属势力或传承，引用知识卡 id |

`technique_type` 建议选项：

```text
cultivation_method  功法
spell               术法
divine_ability      神通
sword_art           剑诀
forbidden_art       禁术
alchemy             炼丹
formation           阵法
other               其他
```

## 地点 location

地点卡承担空间关系和剧情可用性职责。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `controlling_faction_id` | knowledge_ref/null | 控制势力 | 引用势力卡 id |
| `first_seen_chapter_id` | chapter_ref/null | 首次出现章节 | 引用稳定 chapter_id |

## 势力 faction

势力卡体现组织结构、利益关系和行动边界。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `faction_type` | enum | 势力类型 | 宗门、家族、王朝、商会、魔道、联盟、学院等 |
| `leader_id` | knowledge_ref/null | 当前首领 | 引用角色卡 id |

`faction_type` 建议选项：

```text
sect       宗门
family     家族
dynasty    王朝
guild      商会
demonic    魔道
alliance   联盟
academy    学院
other      其他
```

## 物品 item

物品卡跟踪归属变化和能力限制。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `item_type` | enum | 物品类型 | 法宝、丹药、材料、其他等 |
| `grade` | string | 品阶 | 品阶，第一版不强制枚举 |
| `current_holder_id` | knowledge_ref/null | 当前持有人 | 引用角色卡 id |
| `first_seen_chapter_id` | chapter_ref/null | 首次出现章节 | 引用稳定 chapter_id |
| `last_seen_chapter_id` | chapter_ref/null | 最近出现章节 | 引用稳定 chapter_id |

`item_type` 建议选项：

```text
magic_treasure  法宝
pill            丹药
material        材料
other           其他
```

## 规则 rule

规则卡记录世界规则的例外情况。主体规则内容优先写在 `summary`。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `exceptions` | long_text | 例外情况 | 规则例外情况 |

## 事件 event

事件卡不替代章节摘要，只记录对世界状态造成变化的关键事实。

字段：

| 字段 | 类型 | 中文展示 | 说明 |
|---|---|---|---|
| `chapter_id` | chapter_ref/null | 发生章节 | 事件发生或首次确认章节 |
| `description` | long_text | 事件描述 | 事件内容与影响的简要描述 |

注意：字段名必须是 `chapter_id`，不要写成 `hapter_id`。
