# 知识卡字段契约 v2

## 类型列表

第一版支持 8 类知识卡：

| type | 中文名 |
|---|---|
| `character` | 角色 |
| `realm` | 境界 |
| `technique` | 功法 |
| `location` | 地点 |
| `faction` | 势力 |
| `item` | 物品 |
| `rule` | 规则 |
| `event` | 事件 |

第一版不支持：

```text
foreshadow
worldbuilding
```

旧 `worldbuilding` 目录和旧 confirmed 规则卡直接删除，不迁移。

## 通用字段

```json
{
  "id": "knowledge_xxx",
  "type": "character",
  "name": "秦浩轩",
  "aliases": [],
  "summary": "一句话或一段摘要",
  "importance": "core",
  "status": "draft",
  "source_origin": "manual",
  "source_note": "作者手动添加。可写章节、原文摘录、人工说明。", //前端默认-作者手动添加的事件示例,这样作者不想添加时不用多打字
  "created_at": "2026-07-03T00:00:00Z",
  "updated_at": "2026-07-03T00:00:00Z"
}
```

## importance

```text
core    核心
major   重要
normal  普通
minor   次要
```

## status

```text
draft       草稿
active      有效
deprecated  已废弃
```

## source_origin

```text
inbox_fact     Inbox 事实转化
agent_extract  Agent 正文自动提取
manual         人工添加
```

第一版 `agent_extract` 只做预留，不实现真实 Agent 自动提取。

## 类型专属字段规则

类型专属字段必须直接出现在知识卡顶层，不允许放进 `fields` 对象。

正确示例：

```json
{
  "id": "character_001",
  "type": "character",
  "name": "秦浩轩",
  "aliases": [],
  "summary": "主角。",
  "importance": "core",
  "status": "draft",
  "source_origin": "manual",
  "source_note": "作者手动设定。",
  "role_type": "protagonist",
  "identity": "太初教弟子",
  "relationship_summary": "",
  "current_realm_text": "",
  "first_seen_chapter_id": null,
  "last_seen_chapter_id": null,
  "death_chapter_id": null,
  "created_at": "2026-07-03T00:00:00Z",
  "updated_at": "2026-07-03T00:00:00Z"
}
```

错误示例：

```json
{
  "id": "character_001",
  "type": "character",
  "fields": {
    "role_type": "protagonist"
  }
}
```

## 章节引用规则

所有“章节引用”字段必须保存章节实体的稳定 `chapter_id`，不能保存展示章节序号。

正确：

```json
{
  "first_seen_chapter_id": "chapter_0001"
}
```

错误：

```json
{
  "first_seen_chapter_id": "第1章"
}
```

章节序号只用于前端展示和排序，未来可随插入、删除、重排变化。
