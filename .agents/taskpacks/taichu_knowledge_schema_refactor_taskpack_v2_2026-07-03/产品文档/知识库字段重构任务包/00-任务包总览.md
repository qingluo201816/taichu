# 太初知识库字段重构任务包 v2

## 任务目标

本任务包用于修正并执行「知识库卡片字段重构」。Codex 不需要重新阅读全部聊天记录，只需严格按本任务包执行。

本次任务不是兼容旧知识库，也不是迁移旧卡片，而是把知识库字段模型收敛到第一版真正需要的结构。

## 本任务包替代规则

本任务包替代旧的「知识库字段重构任务包」中所有与字段保留、隐藏、高级区展示相关的模糊表述。

尤其要注意：

1. `body` 第一版不维护，不隐藏，不做高级区，不进入模型、接口、前端表单。
2. `tags` 第一版不维护，不隐藏，不做高级区，不进入模型、接口、前端表单。
3. `fields` 第一版不维护，不保留通用对象，不作为类型专属字段容器。
4. `confidence` 第一版不维护，不隐藏，不做高级区，不进入模型、接口、前端表单。
5. `source_refs` 对知识卡第一版废弃，改为 `source_origin` + `source_note`。
6. `relations` 第一版不做，不保留，不做隐藏字段。
7. `foreshadow` 伏笔卡第一版删除，不做兼容，不保留。
8. `personality`、`motivation`、`appearance` 第一版不做。
9. 当前磁盘旧知识卡全部清空，不迁移，不保留旧结构。
10. 后端字段名必须使用正式英文名；前端作者可见文案使用中文。

## 产品背景

太初是面向单个作者、单本玄幻长篇小说的个人 AI 创作 IDE。知识库用于保存作者确认后的结构化小说事实，但第一版只做足够支撑写作、检索和后续 AI 引用的最小结构。

知识库第一版不追求百科全字段，不追求关系图谱，不追求冲突检测。第一版目标是：字段干净、结构稳定、前端可编辑、后端可校验、旧数据不干扰。

## 本任务范围

允许处理：

- 清理 `project_assets/source/knowledge/` 下旧卡片数据。
- 更新知识库领域模型。
- 建立后端知识卡 schema 注册表。
- 更新知识库 API。
- 更新前端知识库表单，使其按 schema 渲染。
- 更新测试。
- 更新 Coding Agent 规则文档，写入「旧知识卡不保留、不迁移、不兼容」。

不允许处理：

- 不改正文编辑器。
- 不改 Inbox 主流程，除非确认事实入库字段必须适配。
- 不改 AI 历史。
- 不改真实 LLM / RAG。
- 不实现关系图谱。
- 不实现伏笔卡。
- 不实现字段高级区。
- 不保留旧 worldbuilding confirmed 卡片。
- 不做旧结构兼容层。

## 阶段执行规则

每个阶段完成后必须停机，返回证据，等待用户确认。不得自动进入下一阶段。不得在停机点前自动 commit。

推荐阶段：

1. Phase 0：Preflight / 规则写入与现状确认
2. Phase 1：旧数据清理与目录收敛
3. Phase 2：后端模型与 schema 注册表
4. Phase 3：知识库 API 与校验
5. Phase 4：前端 schema 驱动编辑界面
6. Phase 5：测试、验收与清理
