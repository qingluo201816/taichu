# 阶段任务

## Phase 0：Preflight / 规则写入与现状确认

### 目标

确认当前知识库旧数据、旧模型、旧前端字段现状，并把“旧知识卡全部清理、不迁移、不兼容”的规则写入项目 Coding Agent 规则文档。

### 允许修改

- `AGENTS.md`
- `CLAUDE.md`
- `.claude/**` 中实际项目规则文档
- 本任务包文档
- 可以新增现状报告文档

### 禁止修改

- 不清理数据
- 不改模型
- 不改 API
- 不改前端业务代码
- 不自动 commit

### 具体任务

1. 读取本任务包。
2. 扫描 `project_assets/source/knowledge/`。
3. 统计旧卡片数量和类型。
4. 扫描知识库后端模型，找出 `body`、`tags`、`fields`、`confidence`、`source_refs`、`foreshadow`、`personality`、`motivation`、`appearance` 的引用。
5. 扫描前端知识库页面，找出旧字段展示入口。
6. 将以下硬规则写入实际 Coding Agent 规则文档：

```text
知识库字段重构阶段，旧知识卡数据不保留、不迁移、不兼容；当前 project_assets/source/knowledge/ 中旧 JSON 可以按任务包要求清空。知识卡第一版不维护 body、tags、fields、confidence、source_refs、relations、foreshadow、personality、motivation、appearance。
```

### 停机点

完成现状报告和规则写入后停止，返回证据，等待确认。

### 验收命令

可以只运行文档和基础检查；如果无代码修改，不强制跑全量测试。

### 返回证据

- 读取了哪些文件。
- 当前旧知识卡统计。
- 旧字段引用清单。
- 已修改的规则文档。
- 后续阶段风险。
