# 纠错与最终决策

## 必须纠正的错误

旧任务包中出现了几类错误表述，本任务包必须修正：

| 错误表述 | 正确表述 |
|---|---|
| `body` 可隐藏或高级区展示 | 错。`body` 第一版不维护，模型/API/前端都不要。 |
| `tags` 默认隐藏 | 错。`tags` 第一版不维护，模型/API/前端都不要。 |
| `fields` 按 schema 展示 | 错。知识卡 JSON 第一版不要 `fields` 包裹对象；类型专属字段用正式英文 key 直接作为卡片字段，由 schema 注册表描述。 |
| `confidence` 可隐藏或高级区展示 | 错。`confidence` 第一版不维护，模型/API/前端都不要。 |
| `source_refs` 作为来源数组 | 错。知识卡第一版废弃 `source_refs`，改为 `source_origin` + `source_note`。 |
| `relations` 关系数组 | 错。第一版太重，取消。 |
| 伏笔卡保留或兼容 | 错。`foreshadow` 第一版删除，不兼容。 |
| 角色卡保留 personality / motivation / appearance | 错。这三个字段第一版不要。 |
| 清理旧数据时迁移旧结构 | 错。当前旧知识卡全部清空，不迁移，不保留。 |

## 第一版最终通用字段

知识卡第一版只保留以下通用字段：

| 字段 | 类型 | 前端展示 | 说明 |
|---|---|---|---|
| `id` | string | 否 | 稳定主键 |
| `type` | enum | 是，展示中文 | 知识类型，决定 schema 和编辑表单 |
| `name` | string | 是 | 主名称，列表和检索主入口 |
| `aliases` | string[] | 是 | 别名、称号、旧名、简称 |
| `summary` | string | 是 | 一句话或一段摘要 |
| `importance` | enum | 是 | 重要程度 |
| `status` | enum | 是，展示中文 | 草稿、有效、已废弃 |
| `source_origin` | enum | 是，展示中文 | 来源方式 |
| `source_note` | string | 是 | 来源说明，自由文本 |
| `created_at` | datetime | 否 | 创建时间，后端保留 |
| `updated_at` | datetime | 否 | 更新时间，后端保留 |

## 第一版禁止字段

知识卡 JSON、API 返回、前端表单、schema 注册表中都不要出现这些字段：

```text
body
tags
fields
confidence
source_refs
relations
personality
motivation
appearance
```

例外：代码注释、测试断言、文档中可以出现这些字段名，用于说明它们被禁止或已删除。

## 来源规则

知识卡不再使用 `source_refs`。

第一版来源使用：

```text
source_origin
source_note
```

`source_origin` 可选值：

```text
inbox_fact     来自 Inbox 待确认事实
agent_extract  Agent 正文自动提取，第一版只预留
manual         人工添加
```

`source_note` 是来源说明自由文本，可以写章节、原文摘要、人工说明等。

有效卡约束：

- 草稿可以没有来源。
- 标记为有效时，必须有 `source_origin`。
- 标记为有效时，必须有非空 `source_note`。
- 草稿补齐来源后不会自动变有效，必须作者点击「标记为有效」。

## 状态规则

`status` 使用：

```text
draft       草稿
active      有效
deprecated  已废弃
```

不使用 `confirmed`，不兼容旧 `confirmed`。

## 伏笔规则

`foreshadow` 第一版删除。

需要执行：

- 后端类型枚举移除 `foreshadow`。
- 前端类型导航移除「伏笔」。
- 数据目录中的 `foreshadow/` 旧数据清空。
- API 不再允许创建 `foreshadow` 类型。
- 测试不再覆盖伏笔卡。
