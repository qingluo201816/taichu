# AI 历史、评测与回放

更新日期：2026-07-05

## 评测范围

评测不是回答质量评分，而是链路检查：

1. 是否调用真实 LLM。
2. 是否构建知识库上下文。
3. 是否保存 Prompt。
4. 是否保存 raw output。
5. 是否成功解析结构化输出。

## 列表字段

- 时间
- 章节
- 功能入口
- 模型
- 状态
- 是否有知识库上下文
- 是否解析成功
- 输入摘要

## 详情字段

- 输入
- 当前选区
- 参考范围
- 检索上下文
- Prompt 快照（默认折叠）
- LLM 原始输出
- 结构化输出
- 错误信息

## Replay

第一版 replay 是回放记录，不是重新执行，不调用 LLM。
