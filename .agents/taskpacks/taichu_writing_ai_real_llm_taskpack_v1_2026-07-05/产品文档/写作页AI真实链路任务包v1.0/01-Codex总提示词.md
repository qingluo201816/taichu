实现：

## 严禁

1. 禁止假 LLM 作为产品路径。
2. 禁止把 Prompt 写成占位句。
3. 禁止 Codex 自己重新设计 Prompt。
4. 禁止每个按钮各写一套后端接口。
5. 禁止绕过知识库检索。
6. 禁止 AI 输出直接写正式知识库。
7. 禁止把英文枚举展示给用户。
8. 禁止引入 MongoDB、Neo4j、ES、独立向量数据库。
9. 禁止新增多 Agent 可视化平台。

## 必须

1. 所有按钮共用统一后端入口。
2. 每个按钮绑定固定 prompt_id。
3. 每次调用保存 Prompt 快照。
4. 每次调用保存知识库检索上下文。
5. 每次调用保存 LLM 原始输出和结构化输出。
6. LLM 配置缺失时，返回中文错误并记录 failed run，不得模拟成功。
7. AI 历史页面可查看一次 run 的完整 trace。
8. replay 只回放记录，不重新调用 LLM。
