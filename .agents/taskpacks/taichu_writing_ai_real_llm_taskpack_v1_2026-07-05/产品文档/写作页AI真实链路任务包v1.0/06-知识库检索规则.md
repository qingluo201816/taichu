# 知识库检索规则

更新日期：2026-07-05

## 默认检索范围

只读取有效知识卡。

不得读取：草稿知识卡、废弃知识卡、Inbox 灵感、Inbox 待确认事实、未采纳 AI 输出、旧结构待删除卡。

## 第一版策略

1. 当前章节、选区、用户输入中的实体词匹配知识卡名称和别名。
2. 匹配摘要、source_note、类型字段中的文本。
3. 如已有 FTS，可加入 FTS。
4. 不强制新增向量数据库。

## 注入 Prompt 的知识上下文格式

```text
【知识 1】
类型：角色
名称：秦浩轩
摘要：……
重要程度：核心
来源说明：……
命中原因：用户选区提到“秦浩轩”
```

## 空结果

如果没有检索到知识：

```text
当前没有检索到可用有效知识卡。模型不得把未检索到的内容说成已确认事实。
```

并记录：

```json
{"used": true, "empty_reason": "当前没有检索到可用有效知识卡", "items": []}
```
