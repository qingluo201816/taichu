# 验收清单

更新日期：2026-07-05

1. 纯对话接入真实 LLM。
2. 续写接入真实 LLM。
3. 润色接入真实 LLM。
4. 设定接入真实 LLM。
5. 建议接入真实 LLM。
6. 证据接入真实 LLM。
7. 章节摘要接入真实 LLM。
8. 灵感接入真实 LLM。
9. 事实接入真实 LLM。
10. 9 个按钮全部走统一 API。
11. 9 个按钮全部使用固定 Prompt。
12. 每次调用保存 Prompt 快照。
13. 每次调用构建知识库上下文。
14. 知识库为空时记录空原因。
15. 每次调用保存 LLM 原始输出。
16. 每次调用保存结构化输出。
17. LLM 配置缺失时返回中文错误，不返回假输出。
18. 续写主展示区只显示正文候选。
19. 事实按钮只生成待确认事实候选，不直接入库。
20. 设定按钮不提供一键入库。
21. AI 历史可查看 run 详情。
22. replay 能回放已有 trace，且不重新调用 LLM。
23. 前端无英文内部枚举。
24. 不修改正式知识库数据。
25. 不破坏写作页保存、选区、章节切换。
