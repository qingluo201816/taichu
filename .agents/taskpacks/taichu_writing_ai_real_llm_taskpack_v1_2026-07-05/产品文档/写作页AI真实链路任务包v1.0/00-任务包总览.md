# 写作页 AI 真实链路任务包 v1.0

更新日期：2026-07-05

## 目标

本任务包用于交给 Codex 执行，目标是把写作页所有 AI 按钮升级为统一真实链路：

**写作页 AI 按钮 → 统一后端工作流 → 知识库检索 → 真实 LLM → 固定 Prompt → 结构化结果 → 调用记录 → 可评测/可回放。**

## 涉及按钮

1. 纯对话
2. 续写
3. 润色
4. 设定
5. 建议
6. 证据
7. 章节摘要
8. 灵感
9. 事实

以上按钮必须全部接入统一 AI 工作流。不得某些按钮真实 LLM，某些按钮继续假输出。

## 核心硬约束

1. Codex 不允许临场设计 Prompt。
2. Prompt 必须使用本任务包《04-固定Prompt模板.md》。
3. 生产路径禁止假 LLM、mock 输出、前端拼接结果。
4. 所有按钮必须先构建知识库上下文，再调用 LLM。
5. 所有调用必须保存 Prompt 快照、检索上下文、LLM 原始输出、结构化输出和错误信息。
6. 所有调用必须有 run_id，可在 AI 历史中查看，可回放 trace。
7. AI 输出不得直接写入正式知识库。
8. 知识库字段不得回退到旧字段：fields、source_refs、body、tags、confidence、relations。
9. 用户可见文案必须为中文。
