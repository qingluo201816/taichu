# 前端按钮接入说明

更新日期：2026-07-05

| 中文按钮 | button_type | 默认参考范围 | 可选参考范围 |
|---|---|---|---|
| 纯对话 | chat | none | none |
| 续写 | continue | chapter | chapter、selection |
| 润色 | polish | selection | selection |
| 设定 | setting | selection | selection、chapter、full_text |
| 建议 | suggestion | chapter | selection、chapter、full_text |
| 证据 | evidence | full_text | chapter、full_text |
| 章节摘要 | chapter_summary | chapter | chapter |
| 灵感 | inspiration | chapter | selection、chapter |
| 事实 | fact | selection | selection、chapter |

前端显示中文，不显示枚举。

结果展示：
- 续写：主区域只展示正文候选。
- 润色：展示润色文本和修改说明。
- 设定：展示设定补充、使用建议、可能影响；不一键入库。
- 建议：展示问题诊断和修改建议。
- 证据：展示结论、依据、推测、未确认点。
- 章节摘要：展示摘要、关键事件、变化、衔接点。
- 灵感：可保存到 Inbox 灵感。
- 事实：可保存到 Inbox 待确认事实，不直接写知识库。
