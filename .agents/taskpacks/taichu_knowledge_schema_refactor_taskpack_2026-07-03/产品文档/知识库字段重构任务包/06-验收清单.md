# 验收清单

更新日期：2026-07-03

## 1. 数据清理验收

- [ ] 当前旧知识 JSON 文件已清理。
- [ ] `worldbuilding/` 旧规则卡不再作为有效目录使用。
- [ ] `foreshadow/` 不再作为第一版知识类型使用。
- [ ] 不存在旧 `confirmed` status 兼容逻辑。
- [ ] 不存在旧 `source_refs` 新建路径。
- [ ] 新目录骨架只包含：角色、境界、功法、地点、势力、物品、规则、事件。

## 2. 后端字段验收

- [ ] 知识卡通用字段符合新契约。
- [ ] 稳定标识统一使用 `id`。
- [ ] 主名称统一使用 `name`。
- [ ] 摘要统一使用 `summary`。
- [ ] 来源说明使用 `source_note`。
- [ ] 来源方式使用 `source_origin`。
- [ ] 新结构不使用 `source_refs`。
- [ ] 第一版不使用 `relations`。
- [ ] 第一版不包含 `foreshadow` 类型。
- [ ] 后端字段名全部为正式英文名。
- [ ] 中文只出现在用户可见 label、placeholder、文档或错误提示中。

## 3. Schema 注册表验收

- [ ] 后端存在知识卡 schema 注册表。
- [ ] 每种类型都有 schema。
- [ ] schema 包含 `field_key`、`label`、`field_type`、`required_when_active`、`options`、`placeholder`、`display_group`、`list_display`、`ai_usage`。
- [ ] 前端表单通过 schema 渲染，不硬编码全部类型字段。

## 4. 状态与校验验收

- [ ] 新建知识卡默认 `draft`。
- [ ] 草稿可以没有来源说明。
- [ ] 草稿不参与 AI 检索和证据回答。
- [ ] 草稿补齐来源后不会自动变有效。
- [ ] 标记有效必须作者点击。
- [ ] 标记有效时校验名称、摘要、来源方式、来源说明。
- [ ] 知识卡不物理删除，只能标记为 `deprecated`。
- [ ] 废弃卡默认隐藏。
- [ ] “只看废弃”可以单独查看废弃卡。

## 5. 类型字段验收

- [ ] 角色字段符合新契约。
- [ ] 角色状态记录作为阶段状态记录处理。
- [ ] 角色不做秘密功能。
- [ ] 角色不做关系数组，使用关系摘要。
- [ ] 境界只保留 `system` 和 `level_order`。
- [ ] 功法字段符合新契约。
- [ ] 地点字段符合新契约。
- [ ] 势力字段符合新契约。
- [ ] 物品字段符合新契约。
- [ ] 规则字段符合新契约。
- [ ] 事件字段使用 `chapter_id` 和 `description`，不存在 `hapter_id` 拼写错误。

## 6. 引用验收

- [ ] 所有章节引用字段保存稳定章节 ID。
- [ ] 不保存展示用章节序号作为事实字段。
- [ ] 所有知识卡引用字段保存知识卡 ID。
- [ ] 前端展示时解析成中文名称。

## 7. 前端验收

- [ ] 知识库一级页面仍可使用。
- [ ] 左侧类型导航无伏笔。
