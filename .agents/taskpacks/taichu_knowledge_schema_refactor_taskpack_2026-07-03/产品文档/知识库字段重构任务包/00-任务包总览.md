# 太初知识库字段重构任务包

更新日期：2026-07-03

## 1. 任务目标

本任务包用于指导 Codex 在 MVP 第一版完成或知识库模块进入重构阶段后，重构太初知识库卡片字段体系。

目标不是迁移旧知识卡，也不是兼容历史结构，而是：

1. 清空当前 `project_assets/source/knowledge/` 中已有旧知识 JSON 文件。
2. 删除旧结构与旧信息，不做保留、迁移、兼容。
3. 建立新的结构化知识卡通用字段。
4. 删除第一版中的“伏笔 foreshadow”知识类型，不保留前端入口，不保留后端兼容。
5. 建立后端知识卡字段 schema 注册表。
6. 前端知识库编辑界面基于后端 schema 渲染，不把字段结构硬编码在前端。
7. 将来源引用从 `source_refs` 数组改为更轻量的 `source_note` 文本和 `source_origin` 来源方式。
8. 所有章节引用字段必须保存章节稳定 ID，不能保存展示用章节序号。
9. 所有后端字段名必须是正式英文名，中文只用于前端标签、占位说明和用户可见文案。

## 2. 产品背景

太初是面向单个作者、单本玄幻长篇小说的个人 AI 创作 IDE。知识库不是独立百科系统，而是服务正文写作、设定一致性、后续 AI 检索和冲突检查的结构化事实层。

当前知识库第一版已经能创建和查看部分结构化卡片，但实际数据里存在新旧结构混用、旧 confirmed 卡片、废弃草稿、空 fields、旧 `source_refs` 结构等问题。用户已确认：这些旧数据不需要保留，重构时直接清理。

## 3. 本任务包的最高优先级规则

如果本任务包与旧代码、旧测试、旧文档冲突，以本任务包为准。

其中最重要的新增规则是：

```text
当前已有知识库卡片全部清掉，不保留旧数据，不迁移旧结构，不保留旧信息。
后续重构时旧知识卡和旧字段兼容都不需要做。
这条规则需要写入项目的 Coding Agent 规则文档，例如 CLAUDE.md、AGENTS.md 或当前仓库实际使用的等价规则文件。
```

## 4. 不属于本任务的内容

本任务不做：

1. 真实 LLM 接入。
2. 真实 RAG 检索效果评估。
3. AI 自动从正文抽取知识的真实能力。
4. 复杂一致性检查。
5. 关系图谱可视化。
6. 伏笔卡设计。
7. 旧知识卡迁移。
8. 删除或重构写作编辑器主体功能。
9. 修改入口虚空视觉系统。

## 5. 推荐执行阶段

1. Phase 0：Preflight / 现状确认与规则写入。
2. Phase 1：数据清理与目录收敛。
3. Phase 2：后端知识卡模型与 schema 注册表。
4. Phase 3：知识库 API 与校验规则。
5. Phase 4：前端 schema 驱动知识卡编辑界面。
6. Phase 5：测试、验收与清理。

每个阶段完成后必须停止，返回证据，等待用户确认。不得自动进入下一阶段，不得在停机点前自动 commit。
