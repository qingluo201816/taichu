# 停止条件与禁止事项

更新日期：2026-07-03

## 1. 必须停止并询问用户的情况

出现以下情况，Codex 必须停止：

1. 无法判断当前仓库实际使用 `AGENTS.md` 还是 `CLAUDE.md` 作为 Coding Agent 规则文档。
2. 删除旧知识 JSON 会影响非测试代码的启动，且原因不明确。
3. 前端或后端测试在任务开始前已经失败，且失败与本任务无关。
4. 需要修改写作编辑器主体流程才能完成知识库字段重构。
5. 需要接真实 LLM 才能继续。
6. 需要实现真实 RAG 才能继续。
7. 需要保留旧知识卡才能通过测试。
8. 需要恢复 `foreshadow` 才能通过测试。
9. 需要把英文内部字段暴露给用户才能完成 UI。

## 2. 禁止事项

1. 禁止迁移旧知识卡。
2. 禁止保留旧结构兼容。
3. 禁止保留旧 `worldbuilding` 规则卡。
4. 禁止恢复 `source_refs`。
5. 禁止恢复 `foreshadow`。
6. 禁止物理删除新结构知识卡的产品功能；只能标记废弃。
7. 禁止把章节展示序号保存为章节引用事实字段。
8. 禁止把中文字段名写入后端模型。
9. 禁止让前端硬编码所有类型字段。
10. 禁止修改后端 AI 工作流、真实 LLM、RAG、入口页视觉。

## 3. Commit 规则

每阶段可以一个 commit，但必须满足：

1. 阶段完成。
2. 测试通过或失败原因已说明。
3. 按证据模板返回。
4. 用户确认后再 commit。

不得在停机点前自动提交。
