# 数据清理规则

更新日期：2026-07-03

## 1. 必须清理的旧数据

当前已有知识卡全部清理，不保留、不迁移、不兼容。

包括但不限于：

```text
project_assets/source/knowledge/character/*.json
project_assets/source/knowledge/event/*.json
project_assets/source/knowledge/foreshadow/*.json
project_assets/source/knowledge/item/*.json
project_assets/source/knowledge/worldbuilding/*.json
```

如果仓库中还有其他旧知识卡 JSON，也一并清理。

## 2. 不保留旧 confirmed 卡

旧 confirmed 规则卡位于 `worldbuilding/`，使用旧 `KnowledgeCard` 和旧 `source_refs` 结构。用户已确认：直接删除，不迁移。

## 3. 不保留旧结构兼容

不要写：

1. 旧字段迁移脚本。
2. 旧 status 映射兼容。
3. 旧 `source_refs` 兼容显示。
4. 旧 `worldbuilding` 目录兼容读取。
5. 旧 `foreshadow` 类型兼容。

## 4. 新目录骨架

清理后保留或创建：

```text
project_assets/source/knowledge/
  character/
  realm/
  technique/
  location/
  faction/
  item/
  rule/
  event/
```

## 5. 规则文档要求

必须把以下规则写入项目实际使用的 Coding Agent 规则文档：

```text
知识库字段重构时，当前已有知识 JSON 文件和旧结构数据不需要保留，不做迁移，不做兼容。旧数据可直接清理；后续以最新知识卡字段契约为准。
```
