# 知识库字段契约

更新日期：2026-07-03

## 1. 知识类型

MVP 第一版知识类型只包括：

| 英文字段值 | 用户可见中文名 |
|---|---|
| character | 角色 |
| realm | 境界 |
| technique | 功法 |
| location | 地点 |
| faction | 势力 |
| item | 物品 |
| rule | 规则 |
| event | 事件 |

`foreshadow` 不进入本轮第一版。伏笔卡暂时删除，不做兼容或保留。

## 2. 通用字段

| 字段 | 类型 | 前端是否展示 | 说明 |
|---|---|---:|---|
| id | string | 否 | 稳定主键 |
| type | enum | 是，展示中文 | 知识类型，决定字段 schema 和编辑表单 |
| name | string | 是 | 主名称，列表和检索主入口 |
| aliases | string[] | 是 | 别名、称号、旧名、简称 |
| summary | string | 是 | 一句话或一段话摘要 |
| body | string | 是 | 非结构化补充说明 |
| tags | string[] | 默认隐藏 | 用户自定义分类，第一版可不要求维护 |
| importance | enum | 是 | 重要程度 |
| status | enum | 是，展示中文 | 草稿、有效、已废弃 |
| confidence | enum | 可隐藏或高级区展示 | 可信度 |
| source_origin | enum | 是，展示中文 | 来源方式 |
| source_note | string | 是 | 来源说明，自由文本 |
| fields | object | 是，按 schema 展示 | 类型专属字段 |
| created_at | datetime | 否 | 创建时间，前端隐藏 |
| updated_at | datetime | 否 | 更新时间，前端隐藏 |

## 3. 废弃字段

`source_refs` 在本轮知识卡新结构中废弃。

不要继续创建、展示或校验 `source_refs`。如果旧数据中有 `source_refs`，本任务中旧数据应直接删除，不做迁移。

`relations` 第一版取消，不做。

## 4. 状态值

实现默认：

| 英文字段值 | 用户可见中文名 | 说明 |
|---|---|---|
| draft | 草稿 | 可以缺少来源说明，不进入 AI 检索和证据回答 |
| active | 有效 | 需要名称、摘要、来源方式、来源说明 |
| deprecated | 已废弃 | 默认隐藏，不进入常规列表 |

## 5. 重要程度

实现默认：

| 英文字段值 | 用户可见中文名 |
|---|---|
| core | 核心 |
| major | 重要 |
| normal | 普通 |
| minor | 次要 |

## 6. 可信度

实现默认：

| 英文字段值 | 用户可见中文名 | 说明 |
|---|---|---|
| explicit | 明确 | 正文明确写出或作者明确确认 |
| inferred | 推断 | 根据上下文推断 |
| uncertain | 不确定 | 暂不可靠 |

## 7. 来源方式

实现默认：

| 英文字段值 | 用户可见中文名 | 说明 |
|---|---|---|
| inbox_fact | 来自 Inbox 事实 | 来自收件箱中待处理事实，经过确认后转成知识卡 |
| agent_extract | Agent 正文自动提取 | 从正文、章节文本中由 AI 自动抽取；第一版保留字段，真实能力可后置 |
| manual | 人工添加 | 作者手动创建或手动补充 |

## 8. 标记有效校验

草稿可以没有来源。

标记为有效时必须满足：

1. `name` 非空。
2. `summary` 非空。
3. `source_origin` 非空。
4. `source_note` 非空。
5. 如果字段 schema 中某个字段 `required_when_active=true`，也必须通过校验。

草稿补齐来源后不会自动变有效，必须作者点击“标记为有效”。

## 9. 引用字段规则

所有“章节引用”字段均保存章节实体稳定 ID，不保存展示用章节序号。

所有“知识卡引用”字段均保存知识卡 ID，前端展示时解析成名称。

章节序号仅用于前端展示和排序，可随插入、删除、重排变化，不能作为事实保存字段。
