# 类型字段契约

更新日期：2026-07-03

## 1. 角色 character

角色卡拆成“角色身份”和“阶段状态”两层。稳定信息放在常规字段，随章节变化的状态进入状态记录。

### fields

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| role_type | enum | 角色定位 | 主角、配角、反派、路人、势力代表 |
| identity | text | 身份 | 出身、身份、公开身份 |
| personality | long_text | 性格 | 性格、行为倾向、语言风格 |
| motivation | long_text | 动机 | 当前核心目标或执念 |
| appearance | long_text | 外貌 | 外貌、服饰、可识别特征 |
| relationship_summary | long_text | 关系摘要 | 人际关系概述，第一版不做 relations |
| death_chapter_id | chapter_ref | 死亡章节 | 若死亡，则记录死亡确认章节 |
| current_realm_text | text | 当前境界 | 如“筑基中期”或“接近筑基” |
| first_seen_chapter_id | chapter_ref | 首次登场章节 | 稳定章节 ID |
| last_seen_chapter_id | chapter_ref | 最近出现章节 | 稳定章节 ID |
| state_records | record_array | 状态记录 | 阶段状态记录 |

### state_records

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| time_point | text | 时间点 | 剧情时间或阶段描述 |
| chapter_id | chapter_ref | 章节 | 稳定章节 ID |
| realm_text | text | 当时境界 | 文本，不强制引用境界卡 |
| location_text | text | 当时位置 | 第一版自由文本 |
| life_status | text | 生死状态 | 生、死、失踪、重伤等，第一版自由文本 |
| camp | text | 阵营 | 第一版自由文本 |
| items_text | text | 持有物 | 第一版自由文本 |
| note | long_text | 备注 | 其他说明 |

第一版不做：

1. 人物秘密。
2. “知道的秘密”。
3. 关系图谱。
4. `relations` 数组。
5. 当前目标字段；如需要，暂写入 `motivation`。

## 2. 境界 realm

境界卡记录大小境界，为角色状态、战力判断、世界规则提供稳定参照。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| system | text | 修炼体系 | 所属修炼体系 |
| level_order | number | 境界排序值 | 数值越大表示境界越高 |

排序值建议：

- 练气一层到九层：11 到 19。
- 筑基初期/中期/后期：21、25、29，或 21、22、23。
- 金丹从 31 开始。

第一版不做：

1. parent_realm_id。
2. breakthrough_condition。
3. ability_boundary。
4. cost_or_risk。
5. typical_manifestation。

特殊需求写入通用字段 `summary` 或 `body`。

## 3. 功法 technique

功法卡区分修炼法门、战斗招式、秘术禁法、辅助技艺。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| technique_type | enum | 功法类型 | 功法、术法、神通、剑诀、禁术、炼丹、阵法等 |
| grade | text | 品阶 | 第一版可用自由文本 |
| practice_condition | long_text | 修炼条件 | 修炼、施展或学习条件 |
| owner_faction_id | knowledge_ref | 所属势力或传承 | 保存势力知识卡 ID |

## 4. 地点 location

地点卡承担空间关系和剧情可用性职责。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| controlling_faction_id | knowledge_ref | 控制势力 | 保存势力知识卡 ID |
| first_seen_chapter_id | chapter_ref | 首次出现章节 | 稳定章节 ID |

## 5. 势力 faction

势力卡体现组织类型和核心权力归属。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| faction_type | enum | 势力类型 | 宗门、家族、王朝、商会、魔道、联盟、学院等 |
| leader_id | knowledge_ref | 当前首领 | 保存角色知识卡 ID |

## 6. 物品 item

物品卡跟踪归属变化和能力限制。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| item_type | enum | 物品类型 | 法宝、丹药、材料、其他等 |
| grade | text | 品阶 | 第一版自由文本 |
| current_holder_id | knowledge_ref | 当前持有人 | 保存角色知识卡 ID |
| first_seen_chapter_id | chapter_ref | 首次出现章节 | 稳定章节 ID |
| last_seen_chapter_id | chapter_ref | 最近出现章节 | 稳定章节 ID |

## 7. 规则 rule

规则卡用于记录世界规则、修行规则、禁忌、例外。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| exceptions | long_text | 例外情况 | 规则的例外情况 |

规则内容本体优先写入通用字段 `summary` 和 `body`。

## 8. 事件 event

事件卡不替代章节摘要，只记录对世界状态造成变化的关键事实。

| 字段 | 类型 | 用户可见中文名 | 说明 |
|---|---|---|---|
| chapter_id | chapter_ref | 发生章节 | 事件发生或首次确认章节 |
| description | long_text | 事件描述 | 事件内容与影响的简要描述 |

## 9. 伏笔 foreshadow

第一版删除，不做兼容，不做保留。
