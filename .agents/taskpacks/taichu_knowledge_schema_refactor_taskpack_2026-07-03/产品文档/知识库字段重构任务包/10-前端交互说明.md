# 前端交互说明

更新日期：2026-07-03

## 1. 页面结构

知识库页面继续作为一级页面存在。

推荐布局：

```text
左侧：类型导航 + 状态筛选 + 新建入口
中间：当前类型知识卡列表
右侧：详情编辑区
```

不要回到大表格编辑模式。

## 2. 类型导航

只展示：

1. 角色
2. 境界
3. 功法
4. 地点
5. 势力
6. 物品
7. 规则
8. 事件

不展示伏笔。

## 3. 列表展示

收缩列表展示：

1. 名称
2. 摘要
3. 状态
4. 重要程度
5. schema 中 `list_display=true` 的少量关键字段

废弃卡默认隐藏，通过“只看废弃”查看。

状态筛选：

1. 全部
2. 草稿
3. 有效

废弃不放在普通状态筛选里。

## 4. 详情编辑区

详情区按分组展示：

1. 基础信息
2. 类型字段
3. 状态记录
4. 来源说明

通用字段展示顺序：

1. 名称
2. 别名
3. 摘要
4. 重要程度
5. 来源说明

`created_at` 和 `updated_at` 前端隐藏。

`tags` 第一版可以隐藏，也可以放在高级区域，但不要求作者维护。

## 5. 新建流程

点击新建知识卡后，先选类型。

点击新建后不立刻写入后端，前端生成临时草稿。

首次点击保存时再写入。

直接新建知识卡默认状态为草稿。

## 6. 标记有效

点击“标记为有效”时，如果缺少名称、摘要、来源方式或来源说明，显示中文错误提示。

草稿补齐来源后不会自动变有效。

## 7. 标记废弃

知识卡不物理删除。

点击“标记废弃”后状态变为已废弃，从常规列表隐藏。

通过“只看废弃”单独查看。

## 8. 用户可见文案

所有用户可见按钮、提示、标签、状态、类型都必须是中文。

禁止出现：

```text
source_note
source_origin
role_type
chapter_ref
knowledge_ref
field_type
status
draft
active
deprecated
```

这些只能存在于代码、API 或调试日志中，不能出现在普通 UI。
