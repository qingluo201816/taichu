# 禁止事项与停止条件

> 更新日期：2026-07-04

## 1. 绝对禁止

```text
1. 不引入 MongoDB。
2. 不引入 RAG。
3. 不引入向量库。
4. 不引入 ES。
5. 不引入 Neo4j。
6. 不引入 GraphRAG。
7. 不做当前卷抽取。
8. 不做全书抽取。
9. 不做批量确认。
10. 不做后台队列。
11. 不做 streaming。
12. 不做复杂 LangGraph interrupt / resume。
13. 不自动写入有效知识库。
14. 不复用 /api/agents/chat。
15. 不复活旧 /chat 独立对话页。
16. 不把候选内容写入 project_assets/source/knowledge/。
17. 不修改 project_assets/source 用户数据，除非是专门测试 fixture。
18. 不让用户界面显示英文内部枚举。
19. 不让 Codex 临场设计 prompt。
20. 不评测文学质量。
21. 不评测写作页回答质量。
22. 不做 RAG 效果评估。
```

## 2. 知识字段禁止

第一版不得输出、维护、前端展示或后端接受以下字段作为正文知识沉淀 Agent 的知识卡字段：

```text
body
tags
fields
confidence
source_refs
relations
foreshadow
personality
motivation
appearance
current_goal
secret
known_secrets
```

## 3. 停止条件

遇到以下情况必须停止并返回证据，不得继续实现：

```text
1. 无法读取正文知识沉淀Agent方案.md。
2. 当前仓库没有可读取的章节 Markdown 服务，且无法在本阶段范围内补齐。
3. 旧 /chat 或 /api/agents/chat 仍存在且与 /agent-workbench 实现冲突。
4. 当前知识库结构不是 v2，且会导致 Agent 写入错误字段。
5. 需要引入 MongoDB 才能继续。
6. 需要引入 RAG/向量库/ES/Neo4j 才能继续。
7. 需要修改 project_assets/source 用户数据才可继续。
8. LLM 工厂或配置缺失，且本阶段无法安全注入测试 mock。
9. 运行测试时出现与本任务相关的失败且无法修复。
10. 前端必须显示英文内部枚举才可继续。
```

## 4. commit 规则

```text
1. 不得在阶段停机点前自动 commit。
2. 阶段完成、测试通过、返回证据并由用户确认后，才可以按用户要求 commit。
3. 每阶段可以一个 commit，但不是 Codex 自主行为。
```
