## 6. update_card 规则示例

已有 active 卡：

```json
{
  "id": "character_qinhaoxuan",
  "type": "character",
  "name": "秦浩轩",
  "summary": "太初教弟子。",
  "current_realm_text": "练气三层",
  "source_note": "人工添加：初始角色卡。",
  "status": "active"
}
```

候选更新：

```json
{
  "candidate_action": "update_card",
  "target_card_id": "character_qinhaoxuan",
  "suggested_card": {
    "current_realm_text": "筑基初期",
    "last_seen_chapter_id": "chapter_0012",
    "source_note": "来自章节《第12章 xxx》。原文摘录：秦浩轩已隐隐触及筑基门槛。"
  }
}
```

第一版确认规则：

```text
current_realm_text 已有非空值，不能自动覆盖。
last_seen_chapter_id 可补充或更新。
source_note 只能追加。
若境界冲突，生成 conflict 或要求 edit-confirm。
```
