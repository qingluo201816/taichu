## 2. 产品定位

太初是面向单个作者、单本玄幻长篇小说的个人 AI 创作 IDE。正文知识沉淀 Agent 是太初第一个真实 LLM + LangGraph Agent。

它的定位固定为：

```text
Markdown 正文 → 候选知识卡 / 更新建议 → 作者审核 → 当前 JSON 有效知识库
```

它不是写作页 AI，不是 RAG，不是图谱推理，不是一次性全书自动入库工具。

## 3. 第一版目标

第一版只做当前章节抽取：

```text
选择当前章节
读取 Markdown 正文
运行 LangGraph
调用真实 LLM
生成候选角色 / 地点 / 势力 / 物品
写入 JSON 中间态
展示运行状态、候选项、LLM 调用记录和评测指标
作者逐条确认、编辑后确认、废弃或稍后处理
确认后写入当前 JSON 有效知识库
写作页后续可以通过知识库服务查询 active 知识卡
```

## 4. 第一版硬决策

```text
1. 第一版不引入 MongoDB。
2. 有效知识库继续使用当前 JSON 知识卡。
3. 但必须抽象 KnowledgeRepository / StructuredKnowledgeRepository。
4. Agent、API、前端不得直接依赖 JSON 文件路径细节。
5. Agent 中间态写入 project_assets/derived/agent_runs/knowledge_extraction/。
6. 候选内容不能写入 project_assets/source/knowledge/，只有作者确认后才能写 active 知识卡。
7. 第一版只抽 character、location、faction、item。
8. 第一版不抽 event、rule、realm、technique、foreshadow。
9. 第一版使用真实 LLM，但不评测文学质量、不评测写作页回答质量。
10. 第一版评测只看结构、链路、候选、节点状态、prompt/response、作者处理结果。
11. 不复用 /api/agents/chat。
12. 旧 /chat 独立对话页和旧 /api/agents/chat 若仍存在，不得复活；应按 Preflight 结论停止或清理。
13. Prompt 必须使用本任务包 `05-固定Prompt模板.md`，不得让 Codex 临场设计。
```

## 5. 阶段总览

```text
Phase 0：Preflight / 文档与仓库状态确认
Phase 1：后端模型、运行 JSON 中间态、KnowledgeRepository 抽象
Phase 2：LangGraph 主图与固定 Prompt 接入
Phase 3：API 契约
Phase 4：前端智能体工作台
Phase 5：评测与回放展示
Phase 6：端到端验收与清理
```

每个阶段内要自动检查，阶段完成后必须按证据模板返回。默认每次只执行一个阶段，除非用户明确授权继续下一阶段。不得在停机点前自动 commit。
