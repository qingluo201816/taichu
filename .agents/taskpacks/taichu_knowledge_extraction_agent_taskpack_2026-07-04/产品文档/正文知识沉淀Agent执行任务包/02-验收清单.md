# 验收清单

> 更新日期：2026-07-04

## 1. 产品边界验收

- [ ] 第一版不引入 MongoDB。
- [ ] 第一版不做 RAG。
- [ ] 第一版不做向量库。
- [ ] 第一版不做 ES。
- [ ] 第一版不做 Neo4j。
- [ ] 第一版不做 GraphRAG。
- [ ] 第一版不做当前卷抽取。
- [ ] 第一版不做全书抽取。
- [ ] 第一版不做批量确认。
- [ ] 第一版不做后台队列。
- [ ] 第一版不做 streaming。
- [ ] 第一版不做复杂 LangGraph interrupt / resume。
- [ ] 第一版不自动写入有效知识库。
- [ ] 第一版不评测文学质量。
- [ ] 第一版不评测写作页回答质量。

## 2. 数据边界验收

- [ ] Markdown 正文继续从章节 Markdown 读取。
- [ ] Agent 中间态写入 `project_assets/derived/agent_runs/knowledge_extraction/`。
- [ ] 候选内容没有写入 `project_assets/source/knowledge/`。
- [ ] 作者确认后才写入 JSON active 知识卡。
- [ ] draft 知识卡不参与候选匹配。
- [ ] deprecated 知识卡不参与候选匹配。
- [ ] active 匹配只基于当前 JSON 知识库。
- [ ] JSON run 文件名符合 `extract_run_<日期时间>_<短ID>.json`。
- [ ] run 文件包含 nodes、llm_calls、raw_candidates、typed_candidates、review_items、metrics、errors。
- [ ] 每次 LLM 调用都保存完整 prompt 和 response。

## 3. 知识卡 schema 验收

- [ ] 第一版只生成 character、location、faction、item。
- [ ] 不生成 event、rule、realm、technique、foreshadow。
- [ ] 不输出 `fields` 包裹对象。
- [ ] 不输出 `body`。
- [ ] 不输出 `tags`。
- [ ] 不输出 `confidence`。
- [ ] 不输出 `source_refs`。
- [ ] 不输出 `relations`。
- [ ] 不输出 personality、motivation、appearance。
- [ ] 所有候选卡都有 name、aliases、summary、importance、source_origin、source_note、evidence_excerpt。
- [ ] source_origin 对 Agent 抽取固定为 `agent_extract`。
- [ ] source_note 是作者可读中文文本，包含章节标题和原文摘录。
- [ ] evidence_excerpt 来自正文原文，长度不超过 300 字。

## 4. LangGraph 工作流验收

- [ ] LoadChapterNode 可读取当前章节 Markdown、chapter_id、display_title、content_hash。
- [ ] SegmentChapterNode 能区分短章整章与长章切片。
- [ ] GeneralExtractionNode 只抽角色、地点、势力、物品。
- [ ] MergeChapterCandidatesNode 能合并章内明显重复候选。
- [ ] TypeDispatchNode 能分发角色与实体。
- [ ] CharacterExpertNode 使用固定角色 prompt。
- [ ] EntityExpertNode 使用固定实体 prompt。
- [ ] NormalizeAndValidateNode 做字段、枚举、空值、chapter_id、来源摘录校验。
- [ ] RunInternalConflictCheckNode 做本轮内部重复和冲突检查。
- [ ] MatchExistingKnowledgeNode 只匹配 active 知识卡。
- [ ] BuildReviewItemsNode 生成 create_card、update_card、conflict、ignore。
- [ ] WriteIntermediateJsonNode 写入完整 JSON 中间态。
- [ ] HumanReview 不进入 LangGraph interrupt / resume。

## 5. API 验收

- [ ] `POST /api/agent-workbench/knowledge-extraction/runs` 可创建当前章节运行。
- [ ] `GET /api/agent-workbench/knowledge-extraction/runs` 可分页查看运行列表。
- [ ] `GET /api/agent-workbench/knowledge-extraction/runs/{run_id}` 返回完整 run detail。
- [ ] `GET /api/agent-workbench/knowledge-extraction/runs/{run_id}/candidates` 可筛选候选。
- [ ] confirm create_card 会写 active 知识卡。
- [ ] confirm update_card 只补空字段或追加 source_note，不覆盖已有非空字段。
- [ ] conflict 不能直接 confirm。
- [ ] ignore 不能 confirm。
- [ ] edit-confirm 可编辑后确认。
- [ ] reject 可标记候选已废弃。
- [ ] defer 可标记稍后处理。
- [ ] 所有用户可见错误文案为中文。

## 6. 前端验收

- [ ] `/agent-workbench` 页面可访问。
- [ ] 主导航恢复“智能体工作台”入口。
- [ ] 左侧显示“正文知识沉淀 Agent”。
- [ ] 四个 Tab 固定为：运行任务、待处理候选、运行详情、评测指标。
- [ ] 右侧详情区可展示当前运行摘要、候选详情、LLM 调用详情、错误信息。
- [ ] 可选择当前章节并开始抽取。
- [ ] 可查看最近运行列表。
- [ ] 可查看待处理候选。
- [ ] 可确认入库、编辑后确认、废弃、稍后处理。
- [ ] prompt/response 默认折叠，可展开查看。
- [ ] 评测指标可见。
- [ ] 用户界面不暴露英文内部枚举。
- [ ] 前端遵守 TAICHU_DESIGN.md。
