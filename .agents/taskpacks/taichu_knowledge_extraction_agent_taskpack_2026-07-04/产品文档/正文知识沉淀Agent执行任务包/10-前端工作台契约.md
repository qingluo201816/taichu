# 前端工作台契约

> 更新日期：2026-07-04

## 1. 页面路由

```text
/agent-workbench
```

旧 `/chat` 独立对话页面和旧 `/api/agents/chat` 不复用。主导航中的“智能体工作台”入口等真实页面壳子完成后恢复。

## 2. 布局

```text
智能体工作台
  左侧：Agent 列表
    - 正文知识沉淀 Agent
    - 未来其他 Agent，占位或禁用
    - 最近运行列表

  中间：当前 Agent 工作区
    - 运行任务
    - 待处理候选
    - 运行详情
    - 评测指标

  右侧：详情区
    - 当前运行摘要
    - 当前候选详情
    - 当前 LLM 调用详情
    - 错误信息
```

四个固定 Tab：

```text
运行任务
待处理候选
运行详情
评测指标
```

## 3. 运行任务 Tab

功能：

```text
1. 选择当前章节。
2. 展示当前选择章节标题。
3. 点击“开始抽取”。
4. 展示运行状态。
5. 失败时显示中文错误。
```

第一版不做：

```text
当前卷抽取
全书抽取
后台队列
流式进度
写作页入口跳转
```

## 4. 待处理候选 Tab

候选状态中文映射：

```text
pending = 待处理
confirmed = 已确认
rejected = 已废弃
deferred = 稍后处理
```

候选动作中文映射：

```text
create_card = 候选新卡
update_card = 候选更新
conflict = 候选冲突
ignore = 建议忽略
```

操作：

```text
确认入库
编辑后确认
废弃
稍后处理
```

规则：

```text
1. conflict 不显示直接确认，只允许编辑后确认。
2. ignore 不显示确认入库。
3. update_card 操作说明必须提示“不覆盖已有非空字段”。
4. 所有英文枚举只在代码中存在，界面必须显示中文。
```

## 5. 运行详情 Tab

展示：

```text
节点状态表
LLM 调用记录
错误信息
完整 prompt
完整 response
解析结果
```

规则：

```text
1. prompt/response 默认折叠。
2. 展开后可复制。
3. 不用来评测文学质量。
4. 不出现“回答质量评分”等文案。
```

## 6. 评测指标 Tab

展示：

```text
本次运行候选总数
角色候选数
地点候选数
势力候选数
物品候选数
候选新卡数
候选更新数
候选冲突数
schema 通过数
schema 失败数
已确认数
已废弃数
待处理数
总耗时
各节点耗时
LLM 调用次数
```

## 7. 视觉规则

必须遵守 `TAICHU_DESIGN.md`：

```text
炭灰控制台画布
深色导航条
灰色线框
白色胶囊主按钮
极光渐变只做少量装饰
用户可见文案全部中文
不做游戏 UI
不做赛博霓虹
不做普通后台风
```
