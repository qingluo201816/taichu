# 证据返回模板

> 更新日期：2026-07-04

Codex 每个阶段完成后必须按此模板返回。不得只写“已完成”。

```text
【阶段】
Phase X：阶段名称

【执行摘要】
本阶段完成了什么，用 3～8 条中文说明。

【读取文件】
列出已读取的关键文件：
- AGENTS.md
- docs/rule.md
- TAICHU_DESIGN.md
- 正文知识沉淀Agent方案.md
- 本任务包相关文件

【修改文件】
逐项列出：
- 文件路径
- 修改目的
- 是否新增 / 修改 / 删除

【未修改确认】
明确说明：
- 未引入 MongoDB
- 未做 RAG
- 未做向量库
- 未做 ES
- 未做 Neo4j
- 未做 GraphRAG
- 未自动写入有效知识库
- 未修改 project_assets/source 用户数据
- 未复用 /api/agents/chat
- 未把候选写入 source/knowledge
- 未让前端显示英文内部枚举

【数据与契约证据】
按本阶段涉及内容填写：
- 新增模型
- 新增接口
- JSON 文件路径
- Repository 抽象
- LangGraph 节点
- Prompt 版本
- API 路由
- 前端页面和组件
- 测试 fixture

【命令结果】
列出实际运行命令和结果：
- 命令
- 是否通过
- 失败摘要
- 若失败，是否为本任务引入

【手动验收】
列出手动操作步骤与结果。例如：
1. 打开 /agent-workbench
2. 选择章节
3. 开始抽取
4. 查看候选
5. 确认入库
6. 查看 active 知识卡

【风险与待确认】
列出风险、未完成项、需要用户确认项。

【下一阶段建议】
只说明下一阶段建议，不得自动进入下一阶段，除非用户明确授权。
```
