# 太初开发态结构说明（.claude）

> 更新日期：2026-07-06

## 定位

`.claude/` 当前承担太初开发态的规则、命令模板、辅助脚本和旧版 Claude Code 兼容材料。项目级 Codex Skills 的当前有效位置是 `.agents/skills/`，但 PRD-to-Plan 流程依赖的 cc-sdd/Kiro 规则和脚本放在 `.claude/`。

## 当前目录职责

```text
.claude/
├── agents/kiro/                         # Kiro 阶段 Agent 定义
├── commands/kiro/                       # Kiro 阶段命令模板
├── rules/                               # 规格拆分、编排和 Kiro 调用规则
├── scripts/spec_dashboard_server.py     # 规格进度 Dashboard
├── skills/prd-requirement-analyzer/     # PRD 文档辅助脚本
├── management/                          # 项目架构说明
├── changelog/                           # 旧开发变更记录
└── skills/                              # 旧 Skill 目录，非当前项目级 Skill 主入口
```

## Kiro/cc-sdd 基础设施

PRD-to-Plan 迁移后新增的核心规则：

- `.claude/rules/SKILL_ORCHESTRATOR_PATTERN.md`：多阶段 Skill 编排规范。
- `.claude/rules/FUNCTION_SPLIT.md`：PRD 功能点拆分规则。
- `.claude/rules/KIRO_COMMAND_CALLING_SPEC.md`：cc-sdd 阶段文件、状态和调用模板。

Kiro 命令模板：

- `.claude/commands/kiro/spec-init.md`
- `.claude/commands/kiro/spec-requirements.md`
- `.claude/commands/kiro/spec-design.md`
- `.claude/commands/kiro/spec-tasks.md`
- `.claude/commands/kiro/spec-impl.md`

Kiro 阶段 Agent 定义：

- `.claude/agents/kiro/spec-requirements-agent.md`
- `.claude/agents/kiro/spec-design-agent.md`
- `.claude/agents/kiro/spec-tasks-agent.md`
- `.claude/agents/kiro/spec-impl-agent.md`

这些文件是 Codex 执行 cc-sdd 流程时读取的模板和约束，不代表必须存在外部 Kiro CLI。

## 规格目录

规格数据放在仓库根目录 `.kiro/`：

```text
.kiro/
├── settings/rules/
│   ├── ears-format.md
│   ├── design-principles.md
│   └── tasks-generation.md
└── specs/
    └── {版本号}/{功能名}/
        ├── spec.json
        ├── requirements.md
        ├── design.md
        └── tasks.md
```

`spec.json` 的核心阶段：

- `initialized`
- `requirements`
- `design`
- `tasks`
- `implementing`
- `completed`

## 辅助脚本

### 规格进度 Dashboard

启动命令：

```powershell
uv run python .claude\scripts\spec_dashboard_server.py --port 8686
```

访问地址：

```text
http://localhost:8686/dashboard.html
```

主要接口：

- `GET /api/summary`
- `GET /api/specs`
- `GET /api/specs/{版本号}/{功能名}`
- `GET /api/logs/{版本号}/{功能名}`

### PRD 图片提取

脚本路径：

```text
.claude/skills/prd-requirement-analyzer/scripts/extract_images.py
```

使用命令：

```powershell
uv run python .claude\skills\prd-requirement-analyzer\scripts\extract_images.py prd-docs\需求文档.docx --output out\V1.0\prd_images
```

DOCX 图片提取使用 Python 标准库。PDF 图片提取需要本地具备 PyMuPDF；如未安装，应先改用文本读取能力或由用户确认是否新增依赖。

## 与 .agents 的关系

- `.agents/skills/`：Codex 可触发的项目级 Skill 入口。
- `.claude/rules/`：PRD-to-Plan 与 Kiro 流程引用的规则源。
- `.claude/commands/kiro/`：阶段命令模板。
- `.claude/agents/kiro/`：阶段 Agent 角色定义。
- `.kiro/specs/`：规格文件产物。
- `prd-docs/`：PRD 输入目录。

## 使用边界

- 所有用户可见内容使用中文。
- Python 命令使用 `uv run python`。
- 不引入工号分配、工时表、Confluence 认证或 Graphify。
- 不把 `.claude/skills/` 作为新增项目级 Skill 的主目录；新增项目级 Skill 应放入 `.agents/skills/`。
